Shield Browser

가볍고 빠른 프라이버시 브라우저 · 광고·트래커 차단 내장

⬇ Windows용 다운로드
Windows 10/11 · 64bit · 무료 · 설치 불필요(압축 풀고 실행)
🚫

광고·트래커 차단

EasyList + EasyPrivacy 필터 내장. 광고 요청 자체를 막아 더 빠르게.

⚡

크롬 수준 속도

Chromium 엔진(Electron) 기반이라 속도는 크롬과 동일.

🔒

웹 추적 방어

DNT/GPC 전송, 권한 기본 거부, WebRTC IP 누출 차단, 깨끗한 UA.

🌐

http·https 모두

붙여넣은 링크 그대로 열림. 선생님들의 http 수업 사이트도 OK.

🧹

원클릭 데이터 삭제

쿠키·캐시·스토리지 한 번에. 종료 시 자동 삭제 옵션.

🪶

가벼움

저사양 노트북도 고려한 메모리 절약 설정.

설치 방법

  1. 위 다운로드 버튼으로 zip을 받습니다.
  2. zip을 압축 해제합니다 (원하는 폴더로).
  3. 폴더 안의 Shield.bat을 더블클릭하면 실행됩니다.

※ 설치 없이 바로 실행되는 포터블 앱이라, Windows SmartScreen이 "알 수 없는 앱" 경고를 띄울 수 있어요. 서명되지 않은 개인 앱이라 그렇습니다 — 추가 정보 → 실행으로 진행하면 됩니다.

정직하게: Shield는 웹사이트·광고사로부터의 프라이버시를 보호합니다(쿠키·트래커·핑거프린트 표면 축소). 기기에 관리자 권한으로 설치된 모니터링/관리 소프트웨어(학교·회사 MDM 등)나 통신사·기관의 망 차단은 우회하지 않습니다 — 어떤 브라우저도 원리상 불가능하고, 의도하지도 않았습니다.
